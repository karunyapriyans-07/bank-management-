# bank-management-
bank management project 
📌 Project Overview

This is a simple Bank Management System developed using C++ with file handling. It allows users to perform basic banking operations through a menu-driven interface.

🚀 Features
Create a new account
Deposit money
Withdraw money
Check account balance
Display all accounts
🛠️ Technologies Used
C++
File Handling (Binary Files)
📂 Files
main.cpp → Main source code
bank.dat → Stores account data (auto-created)
▶️ How to Run
Compile:

g++ main.cpp -o bank

Run:

./bank

📸 Output

Console-based banking system.
